# Сборки движка

Каждая сборка разворачивается в LNMP-песочнице по [SANDBOX.md](SANDBOX.md) и проверяется в браузере. Эталон оформления и поведения — статическое демо в `demo/` на коммите `0a21c112`.

## Сборка 1. Установка

**Схема БД:** версия 2 (шаг 0 — `schema_meta`, шаг 1 — `users`).

### Что работает

- Страница «Установка eStables», пока нет `config/config.php`, и страница со списком ошибок, если конфигурация заполнена неверно.
- Самодеплой: при первом запросе с рабочей конфигурацией проверяется сервер, затем создаётся схема базы. Повторные запросы в базу за версией схемы не ходят (кеш в `var/cache/schema.version`).
- Самообновление: если код новее базы, схема обновляется сама, перед этим делается резервная копия. Пока идёт обновление, остальные запросы получают «Идёт обновление» (503). Если база новее кода, сайт не запускается и объясняет почему.
- Мастер первого администратора по токену из `var/install.token`, с проверкой полей. После создания администратора форма закрывается (404).
- Пустой каталог в оформлении демо: шапка, боковая колонка рубрикатора, хлебные крошки, футер, переключатель темы.
- Страницы ошибок 404, 500 и служебные страницы в стиле сайта.
- Заголовки безопасности, включая строгий Content-Security-Policy без внешних доменов: вся статика лежит локально.
- Консоль: `bin/estables check | migrate | status | create-admin`.

### Как проверить в браузере

1. Без `config/config.php` открыть сайт — инструкция по установке.
2. Создать конфигурацию, обновить страницу — откроется форма «Первый администратор»; в базе появятся таблицы `schema_meta` и `users`.
3. Отправить форму с неверным токеном и коротким паролем — сообщения у полей, введённые значения (кроме паролей) сохраняются.
4. Отправить с токеном из `var/install.token` — «Установка завершена», файл токена удалён.
5. Главная — пустой каталог; `/setup/` — 404; любой несуществующий адрес — 404.
6. Переключить тему на тёмную и обновить страницу — тема сохраняется.
7. Обновление схемы: `UPDATE schema_meta SET value='1' WHERE name='version'`, удалить `var/cache/schema.version`, открыть сайт — схема снова версии 2, в `var/backups/` появился дамп.

### Отличия от демо

- В меню только «Каталог»: пункты «Новые поступления», «Производители», «О справочнике» были в демо заглушками и в план не входили.
- Поля поиска в шапке пока нет — поиск появится в сборке 4.
- В футере нет ссылки «Вход администратора» — вход появится в сборке 2.
- Каталог пуст: рубрикатор — сборка 3, предметы — сборка 4.
- Страницы мастера установки и служебные страницы в демо отсутствуют; их стили собраны в разделе 7 `public/assets/css/estables.css`, всё остальное в этом файле совпадает с `demo/css/estables.css`.
